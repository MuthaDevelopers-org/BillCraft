## Add a language
1. Copy `js/i18n/locales/en.js` to `js/i18n/locales/<code>.js`.
2. Translate every value. Keep each key, and the placeholders in braces (`{name}`, `{number}`, `{words}`, `{lines}`, `{qty}`, `{currency}`, `{unit}`, `{rate}`, `{total}`), exactly as written.
3. Fill in `words`:
   - `zero` and `suffix` (the word for "only")
   - `units`: 100 entries, where index = the number 0 to 99
   - `hundred`, `hundredJoin`, `thousand`, `lakh`, `crore`
   The shared spelling logic is in `js/i18n/numberWords.js`. English uses `hundredJoin: ' and '`; Hindi uses `' '`.
4. In `js/i18n/languages.js`, set the language's `loader` to `() => import('./locales/<code>.js')`.
5. Run `npm test`. The parity tests fail if a key is missing or extra.
6. Check the screens in a browser: the picker label, the step bar, the bill (PDF, PNG and print), and the WhatsApp text.
7. Ask a native speaker to review it, and keep the draft note in the file header until they have.

## Right-to-left (Urdu)
The registry already marks Urdu `dir: 'rtl'`, and the page sets `<html dir>` from it. The layout has not been audited for RTL, so expect fixes when the Urdu file is added.

## Fonts
Devanagari is loaded from Google Fonts (Noto Sans Devanagari) and is in the font stack in `css/variables.css`. Other scripts use the device's own fonts. If a language shows empty boxes, add its font to the Google Fonts link in `index.html` and to `--font-sans`.

## Amounts in words
English output is unchanged from the original app (`numberToWords`). Other languages use the `words` block of their locale file through `createTranslator().words()`.
