# BillCraft — Domestic Business Bill & Invoice Maker

A lightweight, 100% offline-ready, responsive static web utility crafted for domestic businesses, artisans, home creators, and local retail sellers to generate instant sales bills, estimates, and receipts.

---

## ✨ Features

- **Product Catalog Management**: Add products with names, descriptions, categories, SKUs, and unit prices.
- **Dynamic Quantity & Price Math**: Real-time line item total and grand total calculation with automatic number-to-words.
- **4 Invoice Templates**: Modern Minimal, Classic Executive, Artisan Boutique, and Compact Thermal POS Slip.
- **Business Profile Settings**: Seller name, brand name, tagline, phone, address, currency symbol, and default template format.
- **Offline UPI Payment QR Code**: Generates dynamic QR codes automatically without requiring internet access.
- **Multi-Format Export**: Download PDF, save PNG Image, Print, or share formatted WhatsApp summary with 1 click.
- **Responsive Design**: Clean desktop split-screen view and mobile bottom navigation with tab switching.
- **Local Persistence**: Saves all bills and settings in browser `localStorage` with JSON backup/restore.

## 🚀 Running Locally

Open `index.html` directly in any web browser, or run a local server:
```bash
python3 -m http.server 8089
```
Then visit `http://localhost:8089`.
